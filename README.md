One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters.

Entry for the [Rename the Planet bounty on make.fun](https://make.fun/competitions/u-motasimfuad-rename-the-planet-094b0369).

## The line

> Neptune is now 'The Overdue Library Book', because it takes 165 years to come back and nobody remembers checking it out.

Neptune takes 165 years to complete one orbit, so by the time it comes back nobody remembers checking it out. The why leans on Neptune's own trait and fits no other planet.

## Run it

```sh
python3 main.py --out /output/entry.txt   # writes the entry line
python3 main.py --check                   # gate-check: 1-200 chars, UTF-8
python3 main.py --self-test               # write twice, compare bytes
python3 main.py --tournament             # candidate tournament table
```

Python 3.13, standard library only, no network.
